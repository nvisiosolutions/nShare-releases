# nShare

Fast, encrypted file sharing between Macs and Windows PCs on the same network.

## Download

Get the latest version from **[Releases](https://github.com/nvisiosolutions/nShare-releases/releases/latest)**:

| Platform | File |
|---|---|
| macOS 11+ (Apple Silicon & Intel) | `nShare_<version>_universal.dmg` |
| Windows 10/11 (64-bit) | `nShare_<version>_x64-setup.exe` |

Once installed, nShare updates itself: when a new version is out, an **Update** button appears in the app.

## First install (beta builds are not code-signed yet)

**macOS:** open the `.dmg` and drag nShare to Applications. The first time you open it, macOS blocks it. Go to **System Settings → Privacy & Security** and click **Open Anyway**.

**Windows:** run the installer. If "Windows protected your PC" appears, click **More info → Run anyway**. When Windows Firewall asks, allow nShare on **Private networks** so other devices can find you.
